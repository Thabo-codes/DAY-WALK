# Day Walk Website

## About the Project

Day Walk is a footwear retail website created to provide customers
with information about the business and its footwear products.

The website allows visitors to learn about Day Walk, view products,
make product enquiries and find contact information.

## Website Pages

The website contains the following pages:

- Home
- About Us
- Products
- Enquiry
- Contact

## Website Structure

- `index.html` - Home page
- `about.html` - Information about Day Walk
- `products.html` - Footwear products
- `enquiry.html` - Customer enquiry form
- `contact.html` - Contact information and message form

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Target Audience

The website is intended for customers who are interested in
comfortable and stylish footwear for everyday use.

## Project Goals

The main goals of the website are to:

1. Introduce Day Walk to customers.
2. Display footwear products.
3. Provide information about the organisation.
4. Allow customers to make enquiries.
5. Provide contact information.
